# Packbang Store - Customer Facing E-Commerce Portal

Temu-inspired Factory-Direct packaging marketplace for Bangladesh. Built on Node.js, Express, MongoDB, EJS, and WebSockets.

## What's New (Temu-Inspired Upgrades)
1. **Top Guarantee Strip**:
   - Free shipping badge, Old Dhaka factory-direct wholesale pricing, Packbang Buyer Protection, and Lightning Deals alerts.
2. **Temu-Style Header**:
   - Signature vibrant orange branding (`#FB7701`), sleek rounded search bar with instant filter, seller hub link, and live cart item counter.
3. **⚡ Lightning Deals & Flash Sales**:
   - Real-time animated digital countdown clock (`[02]h : [45]m : [18]s`), urgent discount badges (Up to 70% OFF), and factory surplus deals.
4. **Temu 4-Pillar Factory Direct Trust Grid**:
   - Direct from Factory (0% middleman markup), Fast Bulk Logistics (Steadfast Courier 64-district delivery), Packbang Money-Back Guarantee, and Wholesale Price Match.
5. **High-Converting Product Cards**:
   - Temu badge overlays (`⚡ LIGHTNING` / `🔥 TOP SELLER`), discount percentages, social proof star ratings & sales counts (`4.9 ★ (1,240+ sold)`), urgency stock meter (`Only X left`), and instant AJAX `[-]` `[qty]` `[+]` cart controls.

## How to Run
```bash
cd K:\packbang-store

# Run with Node
npm start

# Or in development with auto-reload:
npm run dev
```
Server runs at `http://localhost:3000` (or defined `PORT` in `.env`).
